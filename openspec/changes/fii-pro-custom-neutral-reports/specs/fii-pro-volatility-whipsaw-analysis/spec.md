## Purpose

Analyzes which FII×PRO combinations produce the most intraday volatility (whipsaw) using VIX-predicted range as a benchmark, combining daily stats with 30-minute intraday candle data to identify swing timing, asymmetry, and options strategy suitability.

## ADDED Requirements

### Requirement: VIX-benchmarked whipsaw classification

The system SHALL classify each trading day's intraday volatility using VIX as a benchmark. The metrics SHALL be:
- **Half-VIX** = `vix_predicted_move_pct` / 2 — benchmark for a significant one-directional move
- **Up Ratio** = `intraday_high_pct` / Half-VIX — fraction of VIX budget consumed on upside
- **Down Ratio** = abs(`intraday_low_pct`) / Half-VIX — fraction of VIX budget consumed on downside
- **Total Swing** = `intraday_high_pct` + abs(`intraday_low_pct`) — total ground covered in both directions

Three whipsaw tiers SHALL be defined based on whether BOTH Up Ratio AND Down Ratio exceed a threshold:
- **Whipsaw Extreme**: both > 1.0 (both sides exceeded half the VIX range)
- **Whipsaw Strong**: both > 0.75
- **Whipsaw Moderate**: both > 0.50

#### Scenario: Whipsaw extreme classification
- **WHEN** a day has Up Ratio > 1.0 and Down Ratio > 1.0
- **THEN** it is classified as Whipsaw Extreme

#### Scenario: Non-whipsaw day
- **WHEN** a day has Up Ratio = 0.5 and Down Ratio = 1.5
- **THEN** it is NOT classified as Whipsaw Extreme (only one side exceeded) but IS Whipsaw Moderate

### Requirement: Combination volatility statistics

For each (FII_view, PRO_view) pair, the system SHALL compute:
- **Whipsaw Extreme %**: percentage of days classified as Whipsaw Extreme
- **Whipsaw Strong %**: percentage classified as Whipsaw Strong
- **Avg Total Swing**: mean of Total Swing across all days in the combination
- **Avg Up Ratio / Avg Down Ratio**: mean ratios showing which side dominates
- **Swing Bias**: Avg Up Ratio - Avg Down Ratio (positive = up-biased, negative = down-biased)
- **Avg Range/VIX**: mean of `range_vs_vix_ratio` — whether actual range exceeds VIX prediction

#### Scenario: Volatility stats for all combinations
- **WHEN** FII and PRO views are classified using ±20K neutral threshold
- **THEN** volatility statistics are computed for every (FII_view, PRO_view) pair with at least 1 day

### Requirement: Report output structure

The volatility report `reports/FII_PRO_VOLATILITY_WHIPSAW_ANALYSIS.md` SHALL contain the following sections:
1. **Header with methodology**: Title, dataset metadata, explanation of Half-VIX concept and whipsaw tiers, overall stats
2. **Master Table**: All combinations (≥5 days) sorted by Whipsaw Extreme % descending, with columns for whipsaw rates, total swing, range/VIX, Green%, Avg Chg%
3. **Top 10 Highest Total Swing**: Most volatile combinations by average total intraday swing
4. **Top 10 Lowest Total Swing**: Calmest, most directional combinations
5. **Swing Asymmetry**: Up-biased combinations (swing bias > +0.15) and down-biased combinations (swing bias < -0.15) with their Green% and Avg Chg%
6. **Per-FII-View Sections** (7 sections): Each FII view with PRO breakdown showing whipsaw rates, swing metrics, and volatility insight paragraph
7. **Intraday Swing Timing**: Analysis of when whipsaw extremes occur using 30-min candle data — overall swing patterns, high-first vs low-first sequence, pattern breakdown by FII view
8. **Range vs VIX**: Top 10 combinations that exceed and underperform VIX predictions
9. **Conclusion**: Key findings and actionable rules for straddle/strangle vs iron condor candidates

#### Scenario: Report contains all required sections
- **WHEN** the volatility report is generated
- **THEN** the output markdown file contains all 9 section types listed above

### Requirement: Intraday swing timing from 30-min candle data

The system SHALL use `NIFTY_50_2021-09-13_2026-09-11.csv` (30-minute candles) to determine WHEN intraday highs and lows occur on whipsaw extreme days. For each such day with intraday data available:
- Track the time of the running high and running low across candles
- Classify each into **Morning** (before 12:15) or **Afternoon** (12:15 onwards)
- Determine the **swing pattern**: "Up Morning → Down Afternoon", "Down Morning → Up Afternoon", "Both Morning", or "Both Afternoon"
- Determine the **sequence**: "High First" or "Low First" based on which extreme was reached earlier

#### Scenario: Swing timing computed for whipsaw days with intraday data
- **WHEN** a whipsaw extreme day falls within the intraday data date range (2021-09-13 to 2026-09-11)
- **THEN** swing pattern and sequence are computed from the 30-min candles

#### Scenario: Days outside intraday range excluded gracefully
- **WHEN** a whipsaw extreme day has no matching intraday candle data
- **THEN** it is excluded from the swing timing analysis without error

### Requirement: Single report file generated by dedicated script

The system SHALL generate `reports/FII_PRO_VOLATILITY_WHIPSAW_ANALYSIS.md` using a dedicated script `reports/generate_volatility_report.py`. The script SHALL use ±20K as the neutral zone threshold for FII/PRO classification.

#### Scenario: Volatility report generated successfully
- **WHEN** `generate_volatility_report.py` runs to completion
- **THEN** `reports/FII_PRO_VOLATILITY_WHIPSAW_ANALYSIS.md` exists with non-empty content containing all 9 sections
